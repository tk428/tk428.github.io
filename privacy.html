プライバシーポリシー（ijin-uploader）

最終更新日: 2026年11月8日

1. このツールについて

ijin-uploader は、運営者が自分の YouTube チャンネルに自分で制作した動画をアップロードし、管理するための個人用ツールです。YouTube API サービスを使用しています。このツールを使うことで、利用者は YouTube 利用規約 に同意したものとみなされます。

2. 取得する情報

Google アカウントでの許可（OAuth）を通じて、運営者本人の YouTube チャンネルの基本情報（チャンネル名など）と、アップロード・管理する動画の情報（タイトル、説明文、タグ、公開状態、処理状況）にアクセスします。

3. 使いみち

取得した情報は、動画のアップロード、タイトル・説明文・サムネイル・公開状態の設定、アップロード先チャンネルの確認にだけ使います。広告、販売、分析のための第三者提供は行いません。

4. 保存と共有

許可の情報（アクセストークン）は運営者のパソコン内にのみ保存され、外部のサーバーには送信しません。取得した情報を第三者と共有することはありません。

5. 許可の取り消し

このツールへの許可は、Google アカウントのセキュリティ設定（サードパーティのアクセス）からいつでも取り消せます。取り消すと、保存されている許可の情報は使えなくなります。

6. Google のプライバシーポリシー

YouTube API サービスを通じて扱われる情報には、Google プライバシーポリシーも適用されます。

7. 変更

このポリシーを変更する場合は、このページを更新し、最終更新日を改めます。
